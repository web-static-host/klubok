# Клубок — дизайн веб-версии

Основа — `design-system/DESIGN_SYSTEM.md` и `design-tokens.json` (дизайн приложения «Списки»).
Этот файл говорит, **что берём как есть, что меняем для сайта и что добавляем для Клубка**.
Если правила расходятся — для сайта прав этот файл, во всём остальном — `DESIGN_SYSTEM.md`.

## 1. Берём без изменений

- Цвета и токены светлой/тёмной темы (раздел 2), вариант **без размытия** для карточек (2.2), стекло — только для плавающих панелей (шапка, нижнее меню).
- Шрифт Manrope 400/500/600/700, `cv11, ss01`; шкала размеров (раздел 3).
- Принцип «весь текст одного цвета, иерархия размером и жирностью».
- Скругления: 16 основное, 12 мелкое, 22 строка ввода, 24 шторка, круг — кнопки в строке ввода и аватары.
- Фон экрана: подсветка сверху и справа снизу (раздел 5), шум не нужен.
- Иконки Lucide (`lucide-react`), толщина 2 / 2.4 активная / 1.8 неактивная.
- Акцентный градиент `#14B8A6 → #0891B2` 135° — только главное действие экрана (Создать, Опубликовать, Я попробовал).
- Нажатие — scale 0.96 за 100 мс; появление — fadeUp 400 мс; поп-апы — scaleIn 200 мс.
- Шторки снизу на телефоне, переключатель, сегменты, строки-действия с иконкой-плашкой 40×40 (7.12–7.17).
- Три темы: Системная / Светлая / Тёмная.

## 2. Меняем для сайта

| Что | В приложении | На сайте |
|---|---|---|
| Ширина | телефон | адаптив: телефон < 768, планшет 768–1023, компьютер ≥ 1024 |
| Навигация | нижняя «пилюля» | **телефон** — нижняя пилюля (4 вкладки) + FAB «Создать»; **компьютер** — верхняя шапка: логотип, вкладки «Для вас / Подписки», поиск, кнопка «Создать», аватар |
| Диалоги | только нижние шторки | **телефон** — шторки; **компьютер** — модальное окно по центру (радиус 24, тот же фон `background`, кнопка X 36), ширина 480 для форм |
| Открытый пост | отдельный экран | отдельная страница со своим адресом `/p/:id` (можно делиться ссылкой); на компьютере — 2 колонки: картинка слева, текст справа |
| Наведение мыши | нет | у карточек ленты: затемнение картинки 15% + кнопка «Сохранить» в правом верхнем углу; у кнопок — подложка `activeTab` |
| Фокус с клавиатуры | выключен | обязателен: обводка 2 px `#14B8A6` со смещением 2 px (только `:focus-visible`) |
| Вибрация | есть | нет |
| FAB перетаскивание | есть | нет, FAB только на телефоне, фиксированно справа над меню |

## 3. Новое для Клубка

### 3.1 Логотип
- Квадратная плашка с белым клубком: `public/logo.svg` (без отступов) — иконка сайта и шапки.
- Градиент логотипа `#2DE3C5 → #0A6CB8` (вертикальный) — только в логотипе. В интерфейсе — акцентный градиент из раздела 1.
- В шапке: логотип 32×32 + слово «Клубок» 20/700.

### 3.2 Лента-плитка (masonry) — главный экран «Для вас»
- Колонки: 2 (< 640), 3 (640–1023), 4 (1024–1279), 5 (1280–1535), 6 (≥ 1536). Промежуток 12 (телефон 8).
- Поля экрана 12 (телефон 8), максимальная ширина контента 1600.
- Над лентой — ряд «таблеток» тем: Все, Рецепты, Лайфхаки, Дом, Рукоделие, Сад. Таблетка: радиус full, отступ 14×8, 14/600; выбранная — `activeTab` + обводка акцентом 30%.

### 3.3 Карточка поста в ленте
- Картинка без рамки, радиус **16**, высота по пропорциям фото.
- Поверх картинки слева сверху — метка типа (если не «Фото»): `glass-strong`, радиус full, иконка 12 + 12/600: «Рецепт», «Лайфхак», «До и после».
- Под картинкой (отступ 8): название 14/600 до 2 строк; строка автора: аватар 20 + имя 12/400; справа счётчик «Получилось» — иконка `CheckCircle2` 12 + число 12/600 акцентным цветом.
- Без стеклянной подложки — ленте нужно «воздуха», как у Pinterest.

### 3.4 Лента «Подписки»
- Одна колонка по центру, ширина до 560, промежуток 16 — как в Instagram.
- Карточка: `glass`, радиус 16, отступ 12. Шапка: аватар 36 + имя 14/700 + время 12/400 + «…»; картинка радиус 12; ряд действий: сердце, «Я попробовал», комментарии, справа «Сохранить»; название 14/600 и начало описания 14/400 (3 строки).

### 3.5 Страница поста
- Хлебная строка не нужна; слева сверху «Назад» 40×40 `glass`.
- Блок автора: аватар 44, имя 14/700, «N подписчиков» 12/400, кнопка «Подписаться» (вторичная, 36 высота) — «Вы подписаны» нейтральная.
- Метка **«Оригинал»** у первой публикации; у сохранений в папках всегда показывается автор оригинала.
- **Рецепт:** строка фактов (время, порции, сложность) таблетками; «Ингредиенты» — чек-лист (можно отмечать); «Шаги» — нумерованные карточки `glass`, номер в круге 28 с акцентным градиентом.
- **Лайфхак:** шаги карточками, у шага может быть своя картинка.
- **До и после:** две картинки рядом с подписями «До» / «После».

### 3.6 «Я попробовал» (главная механика)
- Под содержимым поста — раздел «ПОВТОРИЛИ · N»: полоса результата (доля «Получилось» акцентом, «Не получилось» серым), подпись «82% получилось».
- Галерея фото повторивших: квадраты 72, радиус 12, горизонтальная прокрутка.
- Список отзывов: аватар 32, имя 14/600, метка результата (таблетка: «Получилось» — успех, «Не получилось» — ошибка из 7.22), текст 14/400, фото 64.
- Кнопка **«Я попробовал»** — основная (градиент). Открывает шторку/модалку: два больших выбора «Получилось» / «Не получилось» (как сегменты 7.16, с иконками `ThumbsUp` / `ThumbsDown`), необязательное фото, необязательный комментарий, кнопка «Отправить».

### 3.7 Папки (вместо досок)
- Сетка папок: 2 / 3 / 4 / 5 колонок. Обложка — коллаж из 3 картинок (одна большая слева, две справа), радиус 16; под ней название 14/600 и «N идей · M сделано» 12/400.
- В папке: та же плитка, у каждой карточки галочка «Сделано» (круг 28, при отметке — акцентный градиент).
- Сохранение: шторка/модалка «Сохранить в папку» — список папок строками (обложка 40 радиус 12 + название) + «Новая папка».

### 3.8 Профиль
- Аватар 88, имя 24/700, описание 14/400, цифры: публикации, подписчики, «повторили N раз» (сколько раз повторили идеи автора).
- Вкладки-сегменты: «Публикации», «Папки» (у себя), «Повторил».
- Настройки (у себя): тема, выход.

### 3.9 Создание поста
- Шторка «Что создать?» со строками-действиями (7.13): Фото с подписью (`#38BDF8 → #2563EB`), Рецепт (`#FB923C → #F97316`), Лайфхак (`#2DD4BF → #0891B2`), До и после (`#A855F7 → #6366F1`). Эти же градиенты — цвет метки типа.
- Форма: загрузка фото (зона 16 радиус, пунктир `borderStrong`), название, описание, тема; для рецепта — время, порции, ингредиенты по строкам, шаги; для лайфхака — шаги.

## 4. Чек-лист экрана

- [ ] Проверено на ширине 390 и 1440, в светлой и тёмной теме.
- [ ] Главное действие одно и в акцентном градиенте.
- [ ] У картинок всегда есть автор; у сохранённого — автор оригинала.
- [ ] Клавиатурой можно дойти до всех кнопок, фокус виден.
