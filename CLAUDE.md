# Клубок — правила для работы с ИИ

Владелец проекта не программист: объяснять по-русски, коротко, без жаргона.
Правки кода в ответах показывать в формате БЫЛО / СТАЛО.

Текущее состояние и следующие шаги — `docs/STATUS.md`. Обновляй его после каждого этапа.

## Проект
- Картиночная соцсеть идей (между Pinterest и Instagram), без внешних ссылок. Главное — «Я попробовал»: получилось / не получилось, фото и комментарий по желанию.
- Вместо досок — **папки**. Сохранение — ссылка на оригинал, автор оригинала виден всегда.
- Доход — реклама (позже). Продажи картинок нет.
- **Людей на картинках публикаций нет** (лица, тела, селфи) — ни в контенте, ни в тестовых данных. Руки в кадре можно. Аватарки — любые.
- Этапы: 1) веб-прототип (сейчас) → 2) сервер и настоящие данные → 3) приложение Android.

## Дизайн
- Сайт — строго по `docs/DESIGN_WEB.md`; всё, что там не сказано, — по `design-system/DESIGN_SYSTEM.md` и `design-tokens.json`.
- Скриншоты в `design-system/screens/` — эталон характера (стекло, радиус 16, Manrope, бирюзовый акцент).
- Проверять каждый экран на ширине 390 и 1440, в светлой и тёмной теме.

## Код
- Vite + React + TypeScript + Tailwind v4, иконки `lucide-react`, маршруты `HashRouter`.
- Токены цветов — CSS-переменные в `src/index.css`.
- Состояние прототипа — `src/store.tsx` (localStorage). Функции стора потом заменятся запросами к API.
- Перед коммитом: `npx tsc -b && npm run build`. Форматирование: `npx prettier --write "src/**/*.{ts,tsx}"`.
- Публикация — автоматически из ветки `main` через GitHub Actions.
