# Клубок

Картиночная соцсеть идей: рецепты, лайфхаки, дом, рукоделие, сад. Увидел → понял → повторил → отметил «Получилось».

**Тестовая версия:** https://web-static-host.github.io/klubok/

Сейчас это кликабельный прототип сайта: данные тестовые и хранятся в браузере, сервера нет.
Следующий этап — настоящий сервер (вход, база, хранение фото), потом приложение для Android.

## Что внутри

| Папка | Что это |
|---|---|
| `src/` | код сайта (React + TypeScript + Tailwind) |
| `src/data/mock.ts` | тестовые авторы, публикации, отзывы «Я попробовал», папки |
| `docs/DESIGN_WEB.md` | дизайн сайта: что взято из дизайн-системы приложения и что изменено для веба |
| `design-system/` | дизайн-система «Списков» (основа) и логотип Клубка в `design-system/logo/` |
| `.github/workflows/deploy.yml` | автопубликация на GitHub Pages при каждом изменении |

## Запуск на компьютере

```bash
npm install
npm run dev
```
Откройте адрес, который покажет команда (обычно http://localhost:5173/klubok/).
